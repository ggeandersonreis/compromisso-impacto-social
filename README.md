## 🎯 Manifesto

> *"Tecnologia sem propósito social é engenharia de vaidade. Tecnologia com propósito escala dignidade humana."*

Na **RET Tecnologia**, acreditamos que nossas habilidades técnicas carregam uma responsabilidade proporcional ao seu poder. Cada linha de código pode ser mais do que produto comercial — pode ser ferramenta de **democratização, inclusão e fortalecimento da segurança digital global**.

## 🛡️ Frentes de Atuação Social

### 1. 🔓 Open Source — Código Aberto, Impacto Aberto

Seguimos o modelo de **OSPO (Open Source Program Office)** adotado por Google, Microsoft e Red Hat: contribuições sistemáticas, não aleatórias.

| Princípio | Prática | Referência |
|-----------|---------|-----------|
| 🌐 **Acessibilidade** | Ferramentas gratuitas que nivelam o campo | Mozilla, Automattic |
| 🤝 **Colaboração** | Contribuições em projetos da comunidade global | IBM, Shopify |
| 🔍 **Transparência** | Código público, auditável, sob licença MIT | Linux Foundation |
| ♻️ **Sustentabilidade** | Manutenção ativa de dependências críticas | Spotify FOSS Fund |

**Problema que resolve:** Ferramentas comerciais de segurança ofensiva (Burp Suite Pro, Acunetix, Nessus) custam **de centenas a milhares de dólares por ano, por licença** — inacessíveis para pesquisadores independentes, pequenas empresas e comunidades de bug bounty no Brasil e LATAM.

<details>
<summary><strong>✅ O que Cascavel democratiza</strong></summary>

<br/>

- ✅ **100+ plugins** de segurança ofensiva — de recon a exploit
- ✅ **30+ ferramentas de reconnaissance** integradas nativamente
- ✅ Relatórios profissionais (PDF, JSON, Markdown) para entrega a clientes
- ✅ Licença **MIT — 100% livre**, sem vendor lock-in
- ✅ Fortalece a segurança do ecossistema digital brasileiro

</details>

<details>
<summary><strong>🚀 Quick Start — 3 comandos</strong></summary>

<br/>

```bash
# Clone
git clone https://github.com/glferreira-devsecops/Cascavel.git

# Setup
cd Cascavel && pip install -r requirements.txt

# Execute
python3 cascavel.py --help
```

## 🤝 Como Contribuir

Contribuições são bem-vindas! Quer adicionar uma frente de impacto, sugerir parcerias ou melhorar documentação:

1. **Fork** este repositório
2. Crie uma **branch** com sua feature (`git checkout -b feature/nova-frente`)
3. **Commit** suas mudanças (`git commit -m 'feat: adiciona parceria com ONG X'`)
4. **Push** para a branch (`git push origin feature/nova-frente`)
5. Abra um **Pull Request**

> 💡 **Dica:** Siga [Conventional Commits](https://www.conventionalcommits.org/) para mensagens de commit.
